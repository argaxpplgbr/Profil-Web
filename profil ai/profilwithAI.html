Apa itu PPLG?

      
PPLG adalah singkatan dari Pengembangan Perangkat Lunak dan Gim. Di jurusan ini kami belajar membuat program, mulai dari aplikasi desktop, website, sampai gim, dan memahami cara kerja di balik layar sebuah perangkat lunak.

      
Jurusan ini adalah pengembangan dari RPL dengan tambahan materi pembuatan gim.

ASP.NET Core Web API dengan Swagger

      
ASP.NET Core adalah framework C# dari Microsoft untuk membuat backend. Lewat Web API, website atau aplikasi ponsel bisa meminta dan mengirim data ke server. Swagger membuat dokumentasi interaktif otomatis, jadi setiap endpoint bisa dicoba langsung di browser.


      

        
GET
ambil data

        
POST
tambah data

        
PUT
ubah data

        
DELETE
hapus data

Sehari di kelas PPLG

      
Ditulis oleh Arga, Kelas X PPLG

      
Pelajaran di kelas kami hampir selalu diakhiri dengan praktik. Kami menulis kode, menjalankannya, lalu memperbaiki error yang muncul. Awalnya membuat frustrasi, tapi rasanya puas sekali ketika program akhirnya berjalan.

      
Selain praktik di komputer, kami mengerjakan proyek kelompok, mengikuti lomba, dan saling bertukar ilmu. Dari sini saya belajar bahwa menjadi programmer berarti terus mencoba dan tidak takut salah.
